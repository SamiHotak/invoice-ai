# InvoiceAI

Automatic invoice and receipt data extraction with a vision-language model (Qwen2.5-VL) and OCR.

Upload an invoice or receipt ((JPG, PNG or PDF, English)) and get clean structured data
(vendor, invoice number, date, line items, tax, total) as JSON and Excel.

> 🚧 Work in progress. Full documentation, demo and evaluation results coming soon.

## Quick start (Google Colab)

Open `notebooks/01_quickstart.ipynb` in Google Colab with a T4 GPU runtime.
